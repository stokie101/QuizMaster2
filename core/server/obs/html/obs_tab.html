Add these as Browser Sources in OBS

  1. Open OBS and choose the scene for your quiz stream.
  2. Click Sources → + → Browser.
  3. Paste one copied URL into the URL field.
  4. Set the source size to match your canvas or preferred overlay region.
  5. Repeat for the timer, leaderboard, or controls source if needed.

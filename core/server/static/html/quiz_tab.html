How to run a live quiz

  1. Set up OBS browser sourcesAdd the sources on the left to your scene at 1920×1080 and enable 60 FPS.
  2. Configure quiz settingsOpen Quiz Settings to adjust the timer, points, scoring rules, and sounds.
  3. Connect to TikTok LIVELink TikTok from the sidebar and go live before you start the quiz.
  4. Load & startLoad your questions in Controls, then click Start Quiz. Viewers answer with A, B, C, D in chat.

Format & upload quizzes

Required fields: question, answer_a–answer_d, and correct_answer. Optional: type, difficulty, category.

Each CSV row is one question. correct_answer must be a, b, c, or d.

question,answer_a,answer_b,answer_c,answer_d,correct_answer,type,difficulty,category
What color is the sky?,Blue,Green,Red,Yellow,a,multiple_choice,easy,general
2 + 2 = ?,3,4,5,6,b,multiple_choice,easy,math

Common mistakes: missing headers, blank question text, fewer than two answers filled in, or correct_answer pointing to an empty field.

Pro tips

  • Test before going live. Run a test quiz to verify your OBS sources, sounds, and timer settings before streaming.
  • Settings sync instantly. Changes in Quiz Settings apply immediately — no need to restart the quiz or refresh OBS.
  • Use fastest finger wisely. A short threshold rewards viewers who answer quickly; pair it with time-based points for tighter competition.
  • Dock the controls. Add Quiz Controls as a Custom Browser Dock (View → Docks → Custom Browser Docks) for seamless access during streams.

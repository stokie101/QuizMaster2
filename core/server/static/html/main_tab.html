Quick start

  1. Connect the live TikTok username in the TikTok tab.
  2. Go LIVE on TikTok, then press Connect.
  3. Load a CSV quiz in Quiz Builder.
  4. Add the official profile quiz, timer, and leaderboard URLs as OBS browser sources.
  5. Start the quiz from Quiz Settings.

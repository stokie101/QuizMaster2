Quick start

  1. Link TikTok from the sidebar connector.
  2. Go LIVE on TikTok; QuizMaster will connect chat automatically.
  3. Load a CSV quiz in Quiz Builder.
  4. Add the quiz, timer, and leaderboard URLs as OBS browser sources.
  5. Start the quiz from Quiz Settings.
